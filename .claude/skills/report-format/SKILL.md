# report-format — 정기 리포트 서식 규칙

## 발동 상황

- 월간·분기 성과 리포트 작성·초안 요청이 들어올 때 적용해요.
- 리포트 절차 자체는 `docs/월간리포트_지침.md`를 따르고, 이 스킬은 산출물의 **서식**을 고정해요.

## 서식 규칙

리포트는 아래 순서를 그대로 지켜요.

1. **상단 정보**: 제목 · 분석 기간 · 데이터 출처 · 작성일
2. **요약 5줄**: 총 매출/판매량, 채널 구조, 환불 이상치, 설문 불만 Top3, 종합 코멘트 — 각 항목을 한 줄로 정리해요.
3. **표 1**: 채널별 매출 (제품 × 채널, 합계·비중 포함)
4. **표 2**: 환불 급증 × 설문 불만 Top3 교차
5. **다음 기간 액션 3가지**: 월간은 다음 달, 분기는 다음 분기 액션을 3개로 정리해요.
6. **하단 비고**: 데이터 범위 · 미포함 항목 · [추정] 안내

## 참고

- 결론 한 문장 우선, 숫자 출처 태그([참조]/[추정]), 금액 원화 표기 등 보고·숫자 규칙은 `.claude/rules/work.md`를 따라요. (이 스킬에는 중복 기재하지 않아요.)
