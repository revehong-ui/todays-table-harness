# 월간 리포트 만드는 법 (지침서)

오늘의식탁 신제품 성과 리포트를 매달 같은 방식으로 재생산하기 위한 표준 절차입니다.
이 문서는 이번 작업에서 **실제로 수행한 단계만** 기록했습니다.

---

## 1. 준비물

| 파일명 | 역할 | 갱신 주기 |
|---|---|---|
| 판매내역_3개월.csv | 매출·판매수량·환불의 원천 데이터 (컬럼: 날짜·제품명·채널·판매수량·매출액·환불건수) | 매월 (최근 3개월 롤링) |
| 고객설문_응답.csv | 만족도·재구매의향·자유응답 (불만 원인 파악용) | 매월 |
| 경쟁사_리뷰스크랩.txt | 경쟁사 포지셔닝·공통 불만 참고 | 분기 또는 수시 |

> 3개 파일 모두 같은 작업 폴더에 두고, 파일명은 고정합니다. 파일명이 바뀌면 아래 프롬프트의 파일명도 함께 수정합니다.

---

## 2. 데이터 교체 원칙

- **파일은 교체, 형식은 유지**: 컬럼 구조와 파일명은 그대로 두고 내용(기간)만 최신으로 덮어씁니다.
- **분석 기간을 먼저 확정**: CSV의 첫 행·마지막 행 날짜로 실제 기간을 확인한 뒤 리포트 상단에 명시합니다.
- **파일에 없는 숫자는 만들지 않음**: 원가·광고비·마진·목표치는 원천에 없으면 리포트에 넣지 않습니다.
- **추정은 태그로 구분**: 데이터로 확정되지 않은 원인 해석은 `[추정]`으로 표기합니다.
- **금액은 원화(원)**, 비중은 % 로 통일합니다.

---

## 3. 작업 단계 (이번에 수행한 순서)

1. **폴더·파일 확인** — 작업 폴더의 파일 목록과 판매 CSV의 컬럼·행수·기간을 확인.
2. **판매 데이터 집계** — 제품별 / 월별 / 채널별로 판매수량·매출액·환불건수를 합산하고, 객단가(매출÷수량)·환불율(환불÷수량)·채널 비중을 계산.
3. **환불 급증 시점 파악** — 제품·월별 환불을 비교해 이상치를 찾고, 해당 제품을 **일별·주차별**로 쪼개 급증 구간을 특정.
4. **설문 불만 분류** — 만족도 분포를 집계하고, 불만족(1~2점) 자유응답을 정독해 테마별(배송·포장/제품특성/변질 등)로 건수를 분류.
5. **경쟁사 리뷰 참고** — 경쟁사 공통 불만(배송·양·가격 등)을 훑어 자사 이슈와 대조.
6. **교차 확인** — 환불 급증 시점과 같은 기간의 설문 불만을 대조해 원인 가설을 연결(예: 특정 제품 특정 월의 변질 불만 ↔ 같은 시점 환불 급증).
7. **리포트 작성** — 요약 5줄 + 표 2개(채널별 매출 / 불만 Top3 교차) + 다음 달 액션 3개 구조로 MD 작성. 확정 안 된 원인은 `[추정]` 표기.
8. **저장·공유** — 작업 폴더에 MD로 저장하고 파일을 공유.

---

## 4. 산출물 형식 (고정 템플릿)

- 상단: 제목 · 분석 기간 · 데이터 출처 · 작성일
- **요약 5줄**: 총 매출/판매량, 채널 구조, 환불 이상치, 설문 불만 Top3, 종합 코멘트
- **표 1**: 채널별 매출 (제품 × 채널, 합계·비중 포함)
- **표 2**: 환불 급증 × 설문 불만 Top3 교차
- **다음 달 액션 3가지**
- 하단: 비고(데이터 범위·미포함 항목·[추정] 안내)

---

## 5. 재사용용 프롬프트

> 아래 블록을 복사해, 최신 데이터 파일 3종을 폴더에 넣은 뒤 그대로 붙여넣으면 동일한 리포트가 생성됩니다.

```
[역할] 당신은 식품 커머스 데이터 분석가
[맥락] 오늘의식탁 신제품의 월간 성과 리포트 작성
[자료] 작업 폴더의 판매내역_3개월.csv · 고객설문_응답.csv · 경쟁사_리뷰스크랩.txt
[지시] 아래 순서로 분석 후 리포트 초안 작성
  1) 판매 CSV의 기간을 확인하고 리포트 상단에 명시
  2) 제품별·월별·채널별 매출/판매수량/환불 집계 (객단가·환불율·채널비중 계산)
  3) 제품·월별 환불 이상치를 찾고, 해당 제품을 일별·주차별로 쪼개 급증 시점 특정
  4) 설문 불만족(1~2점) 자유응답을 테마별로 분류해 Top3 도출
  5) 환불 급증 시점과 같은 기간 설문 불만을 교차 확인
[제약] 파일에 없는 숫자 생성 금지 / 추정치는 [추정] 태그 / 금액은 원화
[형식] 요약 5줄 + 표 2개(채널별 매출 / 불만 Top3 교차) + 다음 달 액션 3개, MD 파일로 저장
```
