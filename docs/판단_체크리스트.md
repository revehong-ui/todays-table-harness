# 업무 배분 판단 체크리스트

## 결론

반복 업무 6종은 **채팅 1건 · 협업 2건 · 코드 3건**으로 나뉘어요. 한 번 쓰고 끝나면 채팅, 내 파일을 반복해서 다듬으면 협업, 시간에 따라 쌓이거나 팀과 나누거나 자동으로 순환하면 코드예요.

## 판단 3문항 깔때기

위에서부터 순서대로 물어보고, 처음 "예"가 나오는 칸에 배정해요.

1. **한 번 쓰고 끝나나요?** (다음에 다시 안 열어봄) → 예: **채팅(1회성)**
2. **내 파일을 놓고 반복해서 고치고 다듬나요?** → 예: **협업(내 파일 반복)**
3. **시간에 따라 쌓이거나, 팀과 나누거나, 자동으로 순환하나요?** → 예: **코드(축적·팀·자동 순환)**

## 분류 체크리스트 표

| 업무 | 모드 | 판단 근거 |
| --- | --- | --- |
| 신제품 성과 리포트(월간) | ☐ 채팅 · ☐ 협업 · ☑ 코드 | 매달 같은 서식으로 돌고, 달마다 데이터가 쌓이며 에이전트로 자동 순환해요. |
| 고객 문의 응대 문구 | ☑ 채팅 · ☐ 협업 · ☐ 코드 | 문의마다 상황이 달라 한 번 쓰고 끝나는 즉답이라 축적이 필요 없어요. |
| 상세페이지 카피 | ☐ 채팅 · ☑ 협업 · ☐ 코드 | 카피 초안을 내 파일에 두고 여러 번 고쳐 다듬는 반복 작업이에요. |
| 경쟁사 리뷰 모니터링 | ☐ 채팅 · ☐ 협업 · ☑ 코드 | 같은 항목을 주기적으로 모아 시계열로 쌓고 비교하는 순환 작업이에요. |
| 브랜드 톤 점검 | ☐ 채팅 · ☑ 협업 · ☐ 코드 | 톤 기준 파일을 놓고 콘텐츠를 반복해서 대조·수정하는 작업이에요. |
| 주간 매출 확인 | ☐ 채팅 · ☐ 협업 · ☑ 코드 | 매주 같은 지표를 집계·비교하고 데이터가 계속 쌓여요. |

## 세부 내용

- **채팅(1회성)** — 고객 문의 응대 문구
  즉답 성격이라 대화 한 번으로 끝내요. 자주 나오는 유형이 보이면 그때 협업 문서로 승격해요.
- **협업(내 파일 반복)** — 상세페이지 카피, 브랜드 톤 점검
  내 파일을 기준으로 반복해서 고치는 일이에요. 파일 하나를 정하고 버전을 이어가며 다듬어요.
- **코드(축적·팀·자동 순환)** — 신제품 성과 리포트(월간), 경쟁사 리뷰 모니터링, 주간 매출 확인
  데이터가 시간에 따라 쌓이고 주기적으로 반복돼요. 서식과 절차를 고정해 자동 순환에 태워요.

## 다음 할 일 / 제안

- 코드 3종은 서식·집계 기준을 먼저 고정해요. 월간 리포트는 이미 `docs/월간리포트_지침.md`가 있으니 경쟁사 모니터링·주간 매출도 같은 방식으로 표준 서식을 만들어요.
- 협업 2종은 기준 파일을 각각 하나씩 지정해 버전 관리를 시작해요.
- 채팅으로 둔 고객 문의는 반복 유형이 쌓이면 표준 답변 문서로 옮겨 협업 모드로 올려요.
